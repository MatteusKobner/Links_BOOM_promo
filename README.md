# Boom Promo — Página de links

Página estática pronta para Vercel.

## Como adicionar produtos futuramente

Edite `products.json` e copie este modelo:

```json
{
  "id": "nome-curto",
  "name": "Nome do produto",
  "description": "Descrição curta",
  "price": "R$ 99,90",
  "store": "Mercado Livre",
  "url": "SEU LINK DE AFILIADO",
  "badge": "Oferta",
  "features": ["Benefício 1", "Benefício 2"],
  "active": true
}
```

Coloque uma vírgula entre os produtos.

## Publicação

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Na Vercel, escolha `Add New > Project`.
4. Importe o repositório.
5. Framework Preset: `Other`.
6. Não precisa de Build Command.
7. Clique em `Deploy`.

Depois use a URL gerada pela Vercel no campo de links do seu canal.
